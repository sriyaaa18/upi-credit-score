# Alternative Credit Scoring for India's Gig Economy Using UPI Transaction Data

An alternative credit scoring system that converts UPI transaction history into a bankable, explainable credit score for gig workers, street vendors, and micro-merchants who lack formal credit history.

## Problem
150M+ Indians transact regularly via UPI but are excluded from formal 
credit due to lack of salary slips, ITR filings, or CIBIL history.

## Solution
Behavioral scoring model using income regularity, cash-flow consistency, 
and transaction patterns — connected to a mock lender-matching dashboard.

## Tech Stack
React, Python (FastAPI), scikit-learn, PostgreSQL

## Status
Built for Citi & NPCI Drunix Hackathon 2026.
